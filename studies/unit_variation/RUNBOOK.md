# 실험 실행 안내 (선우용)

`PLAN.md`의 실험을 실제로 하는 순서다. 코드는 미리 가상 서보로 끝까지 돌려 봤다(`dryrun.py`).

## 1단계: 사기 (STS3215 먼저, Dynamixel은 그다음)

가격은 2026-10-02에 확인했다. 해외 직구 값은 배송비와 환율에 따라 달라진다.

**1차: STS3215만 (약 15~20만 원)**

| 물건 | 수량 | 대략 가격 | 메모 |

| Feetech STS3215 **7.4 V, 1/345 기어** | 5 | 1개 16~32달러 | 판매처 두 곳에서 3개 + 2개. 기어비가 1/191, 1/147인 것과 12 V 버전은 사지 않는다 |
| Waveshare Bus Servo Adapter (A) | 1 | 약 5달러 | PC와 서보를 잇는 보드. SO-101 키트에 들어 있는 것과 같은 종류면 그걸 써도 된다 |

## 2단계: 지그 만들기

- **팔**: 축 중심에서 100 mm, 150 mm 자리에 추를 달 구멍을 뚫는다(XL330용은 110 mm, 170 mm). 서보에 딸려 오는 원판 혼에 나사로 고정한다.
- **고정대**: 서보 장착 귀를 나무 블록이나 바이스에 단단히 고정한다. 팔이 ±90°까지 휘둘러도 흔들리지 않아야 한다.
- **두 자세**: 수직(팔이 아래로 늘어짐)과 수평(서보 축이 세로로 서고 팔이 바닥과 평행하게 돈다). 블록을 90° 돌려 놓으면 두 자세를 다 쓸 수 있다.
- **질량 기록**: 추 질량(kg)과 팔 질량(kg)을 저울로 재서 적는다. 명령어에 넣는다.

안전: `lift_and_drop` 동작은 팔을 들어 올린 뒤 힘을 끈다. 팔이 떨어지며 흔들리므로 손과 얼굴을 치운다.

## 3단계: 컴퓨터 준비

```bash
git clone https://github.com/bluvtx09/partgap && cd partgap
scripts/fetch.sh                  # BAM 코드와 기존 로그
pip install -r requirements.txt rustypot pyarrow
```

서보마다 ID를 1로 두고 하나씩만 연결한다(새 서보는 보통 ID 1). 포트 이름은 Windows에서 `COM3` 같은 형태, Mac에서 `/dev/tty.usbmodem...`, Linux에서 `/dev/ttyACM0`이다.

서보에 이름표를 붙인다: u1~u5 (STS), x1~x3 (XL). 어느 판매처에서 산 것인지도 적는다(A, B).

**팔 달기**: 서보를 0 위치(엔코더 한가운데)에 세워 둔 채로 팔을 단다.

```bash
cd studies/unit_variation
python bench/center.py --servo sts3215 --port /dev/ttyACM0
```

서보가 0에서 버티는 동안 팔이 정확히 아래로 늘어지게 혼에 고정하고 Enter를 누른다.
위치 제한 경고가 나오면 그 서보는 이미 다른 팔에 쓰였던 것이니, 새 서보를 쓰거나 제한을 풀고 다시 한다.

## 4단계: 재기

서보 하나당 세션 2번이다. 세션 2는 **다른 날**, 서보를 지그에서 **떼었다가 다시 달고** 한다. 세션 시작 전에 전원을 껐다 켠다.

```bash
# studies/unit_variation 폴더에서
# 세션 1 (약 15분). 프로그램이 추 위치와 지그 자세를 바꾸라고 할 때마다 따라 하고 Enter
python bench/record.py --servo sts3215 --port /dev/ttyACM0 --unit u1 --session 1 \
    --mass 0.512 --arm-mass 0.031 --vin 7.4 --seller A
# 다른 날, 다시 장착한 뒤 세션 2
python bench/record.py --servo sts3215 --port /dev/ttyACM0 --unit u1 --session 2 \
    --mass 0.512 --arm-mass 0.031 --vin 7.4 --seller A
```

XL330은 `--servo xl330 --vin 5.0`, 추는 약 0.12 kg으로 바꾼다.

- 처음 연결할 때 서보의 공장 설정을 `factory_registers.json`에 저장하고, 끝나면 그 값으로 되돌린다.
- 로그는 `data/raw/<서보>/<이름>/s<세션>/`에 쌓인다. 중간에 끊기면 같은 명령을 다시 실행하면 된다(같은 이름의 로그는 덮어쓴다).
- 하나 재고 나면 `data/raw` 폴더를 압축해서 보내 주세요. 첫 개체에서 이상한 점(예: 팔이 0에서 많이 벗어남)을 먼저 확인하는 게 좋다.
