# Phase 4 진입 판단 — 사전 등록 (결과를 보기 전에 작성, 2026-10-01)

## 쉬운 말로

Phase 3에서 같은 서보(Feetech STS3215)라도 **개체마다 마찰이 달라서**, 한 개체로 만든 시뮬이 다른 개체를 잘 맞추지 못한다는 걸 봤다.
특히 모터를 끄고 팔이 중력에 떨어질 때(역구동) 차이가 컸다.

빌드맵 Phase 4의 진입 질문은 이것이다. **"관절 구조를 바꾸면(평행링크 등) 이 차이를 줄일 수 있는가?"**
시제품을 만들기 전에, 실제로 측정된 두 개체의 마찰을 그대로 써서 시뮬로 먼저 확인한다.

## 무엇을 "오차"로 보나

- 시뮬 = DB 값(개체 A: Rhoban의 STS3215 7.4V, M6 모델)으로 계산한 움직임
- "실물" = 마찰만 개체 B(T-K-233의 STS3215 12V, M6 모델)로 바꾼 같은 서보
  (모터 상수는 A로 통일해서, 개체 사이의 마찰 차이만 남긴다)
- 오차 = 둘의 출력 각도 차이의 평균 절대값(도). 방향을 바꿔(B로 시뮬, A가 실물) 한 번 더 계산해 평균한다.
- 동작: Phase 3의 7.4V 로그 100개에 기록된 명령(목표 각도, 토크 켬/끔)과 하중을 그대로 쓴다.
  구동 구간(토크 켬)과 역구동 구간(토크 끔)을 따로 본다.

## 비교하는 구조

| 이름 | 구조 | 쉬운 설명 |
|---|---|---|
| S0 기준 | 서보 하나가 팔을 직접 돌림 | 지금 흔한 방식 |
| S1 고이득 피드백 | S0과 같고, 출력단 위치 제어 게인 4배 | "출력단 센서로 국소 피드백"의 효과만 따로 |
| S2 감속 링크 2:1 | 서보가 2바퀴 돌 때 팔이 1바퀴 (지렛대·링크) | 링크로 오차를 기구학적으로 나누는 효과 |
| S2b 감속 링크 4:1 | 위와 같고 4:1 | 비율을 키우면 어떻게 되는지 |
| S3 병렬 2개 | 서로 다른 개체 서보 두 개가 같은 팔을 함께 돌림 | 병렬 다리처럼 여러 경로가 하중을 나눔 |

S3의 시뮬은 "A 두 개", 실물은 "A 하나 + B 하나"다(개체를 고를 수 없으니 섞여 들어온다는 가정).
비교 방향을 바꿀 때는 시뮬 "B 두 개", 실물 "A+B"다.

## 판정 기준 (미리 고정)

- 어떤 구조가 S0 대비 **오차를 50% 이상 줄이면** "유의미한 저감"이다. 구동 구간과 역구동 구간을 각각 판정한다.
- **Phase 4 진입 조건**: 링크 계열(S2, S2b, S3) 중 하나 이상이 **역구동 구간** 오차를 50% 이상 줄인다.
  (구동 구간 오차는 Phase 3에서 이미 작았으므로, 문제가 된 쪽은 역구동이다.)
- 대가도 함께 적는다. S2·S2b는 최고 속도가 비율만큼 줄고, S3는 서보가 두 배 든다.

## 확인 절차

- 내 다관절 시뮬레이터를 S0(서보 1개, 비율 1)로 돌린 결과가 BAM 시뮬레이터와 같아야 한다(최대 차이 1e-9 rad 이하).
- 수치 오차: 시간 간격 5 ms와 1 ms 결과가 같은 판정을 내는지 본다.

## 한계 (미리 적어 둠)

- 개체 쌍이 하나뿐이고, 두 개체는 전압 버전도 다르다(Phase 3 Q2와 같은 한계).
- 백래시(기어 유격)는 BAM 모델에 없어서 다루지 못한다. 링크·병렬 구조의 가장 큰 장점(예압으로 유격 제거)은 이 시험에 안 들어간다.
- 링크 자체의 마찰·유연성은 0으로 둔다(이상적 링크). 실제 링크는 마찰을 더한다.
